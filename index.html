Entregas do projeto

O repositório contém o dashboard Streamlit, notebook de análise, base de dados, README e esta página para publicação no GitHub Pages.

Dashboard interativo

Filtros por ano, mês, região, estado, cidade e temporada, com KPIs e gráficos em Plotly.

Análise exploratória

Notebook com leitura da base, preparação dos dados, KPIs, visualizações e interpretação.

Conclusão executiva

Síntese dos padrões encontrados para comunicar impacto econômico, sazonalidade e destinos relevantes.
